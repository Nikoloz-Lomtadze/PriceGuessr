# PRICEGUESSR 

### თამაშის შესახებ
PriceGuessr არის OOP-პარადიგმაზე შექმნილი გასართობი თამაში რომლის მიზანია გამოიცნო ebay-ის მარკეტფლეისიდან აღებული ორი ნივთიდან რომელია უფრო ძვირი. თამაშს აქვს 3 რეჟიმი: Solo, Multiplayer და VsBot. ეს არის იდეალური თამაში როცა გინდა სწრაფად გაიყვანო დრო მოსაბეზრებელ მომენტში. პროგრესის სანახავად თამაში გვთავაზობს ორ ოფციას, თამაშების ისტორია სადაც ვნახავთ ბოლო 10 თამაშს და  ანალიტიკა სადაც უფრო დეტალურად არის ნაჩვენები ჩვენი პროგრესი.

### Requirements 
- Windows
- Python 3
- Internet connection
- api-ის მონაცემები

## როგორ გავუშვათ ეს თამაში?
1. დარწმუნდით რომ პითონი ინსტალირებულია
2. გაუშვით ბრძანება ცონსოლში: pip install -r requirements.txt
3. გაუშვით ბრძანება ასევე კონსოლში python main.py

### გამოყენებული მოდულები
- pyqt5 (ვიზუალი)
- pygame (აუდიო)
- requests (აპის გავუგზანოთ რექუესთები)
- sqlite3 (ლოკალური ბაზა)
- sys (აპლიკაციის ჩართვა და გამორთვა)
- random (რანდომ ნივთების მიღება)
- base64 (api-თვის encoding)
- enum (თამაშის სტილების დეფინიცია)
- pathlib (დირექტორიების გამართვა)

### რა  რისთვისაა

*ძირითადი ფაილები*
- main.py უშვებს აპლიკაციას, ქმნის მთავარ მენიუს და ერთმანეთთან აკავშირებს ეკრანებს.
- Config.py ინახავს eBay API-ის მონაცემებს.
- requirements.txt შეიცავს პროექტისთვის საჭირო Python ბიბლიოთეკებს.

*თამაშის ლოგიკა*
- adaptive.py მოთამაშის წინა პასუხების მიხედვით არჩევს პროდუქტის შემდეგ კატეგორიას.
- analytics.py ითვლის თამაშების, გამარჯვებების, ქულებისა და საუკეთესო შედეგების სტატისტიკას.
- audio.py მართავს ფონურ მუსიკასა და ხმოვან ეფექტებს.
- auth.py მართავს მომხმარებლის რეგისტრაციასა და ავტორიზაციას.
- bot.py მართავს ბოტის არჩევანს, ქულებსა და შედეგებს.
- database.py უკავშირდება SQLite-ს და ქმნის საჭირო ცხრილებს.
- ebay_api.py უკავშირდება eBay API-ს და იღებს პროდუქტების ინფორმაციას.
- game.py ქმნის რაუნდებს, ამოწმებს პასუხებს, ითვლის ქულებს და ინახავს შედეგებს.
- history.py მონაცემთა ბაზიდან იღებს მომხმარებლის წინა თამაშებს.
- items.py არჩევს პროდუქტებს და API-ის მონაცემებს თამაშის ობიექტებად გარდაქმნის.
- models.py აღწერს მომხმარებლის, პროდუქტის, რაუნდის, სესიისა და შედეგის ობიექტებს.
- multiplayer.py მართავს ორმომხმარებლიან თამაშს, პასუხებს, ქულებსა და გამარჯვებულს.
- paths.py განსაზღვრავს სურათების, აუდიოსა და მონაცემთა ბაზის მისამართებს.
- service.py ერთმანეთთან აკავშირებს ინტერფეისს, თამაშის ლოგიკას, API-სა და მონაცემთა ბაზას.

*მომხმარებლის ინტერფეისი*
- active_game.py აჩვენებს პროდუქტებს, ტვირთავს სურათებს და ამუშავებს მოთამაშის პასუხებს.
- analytics_screen.py აჩვენებს სტატისტიკას, პროგრესსა და ქულების გრაფიკს.
- history_screen.py აჩვენებს და ფილტრავს მომხმარებლის წინა თამაშებს.
- result_screen.py აჩვენებს გამარჯვებულს, საბოლოო ქულასა და თამაშის გამეორების ღილაკებს.

*რესურსები*
- assets/images/ შეიცავს ფონებს, ლოგოებს, ღილაკებს, აიქონებსა და სხვა გრაფიკულ რესურსებს.
- assets/audio/ შეიცავს ფონურ მუსიკასა და ხმოვან ეფექტებს.

### როგორ მოძრაობს კოდი
- როცა ვუშვებთ კოდს: main.py → service.py → database.py → მთავარი მენიუ
- ავტორიზაცია: main.py → service.py → auth.py → database.py
- თამაშის დაწყება: main.py → service.py → adaptive.py → game.py
- პროდუქტის მიღება: game.py → items.py → ebay_api.py → eBay API
- პროდუქტის ჩვენება: game.py → service.py → active_game.py
- პასუხის შემოწმება: active_game.py → service.py → game.py → models.py
- თამაშის დასრულება: game.py → database.py → priceguessr.db
- შედეგების ჩვენება: game.py → active_game.py → result_screen.py
- ისტორია და ანალიტიკა: 
history_screen.py   → service.py → history.py   → database.py
analytics_screen.py → service.py → analytics.py → database.py
